# March7th Assistant 网页端控制面板

为 [moesnow/March7thAssistant](https://github.com/moesnow/March7thAssistant) 的 Docker 部署提供的网页端控制面板。官方 Docker 版没有图形界面，只能改配置文件、看容器日志；这个面板把 Windows 端 Launcher 的常用功能搬到了网页上，手机也能用。

> 非官方第三方项目，与 March7thAssistant 官方无关。

## 功能

- **容器控制**：启动 / 停止 / 重启 M7A 容器，查看运行状态与云游戏剩余时长
- **快捷任务**：一键跑单个子任务（每日、清体力、混沌回忆、虚构叙事、末日幻影、模拟宇宙、差分宇宙、货币战争、领奖励、界面测试、角色面板导出等），跑完自动恢复主容器
- **实时日志**：按日期查看、关键字过滤、自动刷新；扫码二维码与游戏截图浏览
- **设置**：240+ 个配置项按分组折叠展示，带搜索与快捷导航；改配置时对 `config.yaml` 做原地手术式修改，不破坏注释与格式
- **结构化编辑器**：队伍（角色可搜索下拉 + 秘技下拉）、支援名单、差分站点优先级、关卡范围、副本队伍、每日任务开关、兑换码、通知模板，不用手写 YAML
- **角色名单**：内置 105 名角色中英文对照，供队伍编辑器选用
- **版本检查与一键更新**：拉取新镜像、对比镜像 ID、自动重打排队补丁并校验、重建容器，失败自动回滚旧镜像
- **体力计划**：编辑 `power_plan`

## 部署

要求：已用 Docker 部署 March7thAssistant，且 M7A 容器名为 `m7a`。

```bash
git clone https://github.com/hu847266h/march7th-assistant-web-panel.git
cd march7th-assistant-web-panel
```

修改 `docker-compose.yml` 里的卷挂载路径，使 `/m7a` 指向你本机的 M7A 目录（即含有 `config.yaml`、`logs/` 的那个目录），然后：

```bash
docker compose up -d --build
```

面板监听 `127.0.0.1:8090`。如需从其他设备访问，请自行用反代（Caddy / Nginx）转发，并务必加上鉴权——**面板本身没有登录功能**，直接暴露到公网等于把服务器控制权交给所有人。

环境变量：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `M7A_DIR` | `/m7a` | M7A 目录挂载点 |
| `DATA_DIR` | `/data` | 面板数据目录（角色面板导出物） |
| `PORT` | `8090` | 监听端口 |

## 前端

`app.py` 是单文件程序，前端页面以内嵌字符串形式包含在内。`page.html` 是同一份页面的可编辑源码，两者内容一致；改完前端后，把 `page.html` 的内容替换进 `app.py` 的 `PAGE` 常量即可（页面不依赖任何外部资源）。

## 工作原理（简述）

- 通过挂载的 `docker.sock` 调用 Docker API 启停容器、拉取镜像、创建一次性任务容器。
- 读 `logs/` 下的日志文件解析运行状态与剩余时长；二维码与截图直接读日志目录下的图片。
- 设置保存时按 key 定位 `config.yaml` 的对应行做原地替换，保留注释；结构化字段整体替换对应顶级块。
- 一键更新时从新镜像中提取上游 `cloud.py`，按锚点自动重打排队补丁（上游漂移导致锚点对不上时安全中止、什么都不动），编译校验通过后才写回并重建。
